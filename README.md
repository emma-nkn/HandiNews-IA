♿ HandiNews - Tout sur l'Innovation Handicap à Saint-Denis
HandiNews est une plateforme dynamique dédiée à la veille technologique et aux initiatives locales en faveur de l'accessibilité. Propulsée par une intelligence artificielle, l'application centralise et simplifie l'accès à l'information pour les citoyens de Saint-Denis et les acteurs de la HandiTech.

## Fonctionnalités Clés

Filtrage par Catégorie : Accès rapide aux actualités (Innovation, Sport, Accessibilité, Initiatives locales).

Formulaire de Contact Sécurisé : Intégration professionnelle via EmailJS pour connecter les porteurs de projets à la mairie.

Design Inclusif : Interface moderne conçue avec Tailwind CSS, respectant les principes d'ergonomie pour une meilleure accessibilité.

Veille IA Automatisée : Un agent intelligent parcourt le web pour dénicher les dernières innovations mondiales et locales.

## Stack Technique

Frontend : React 18, Tailwind CSS, Lucide React (Icônes).

Navigation : React Router DOM.

Backend & Mails : Node.js, Express / EmailJS .

Base de Données : PostgreSQL .
